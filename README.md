ПИнфо - это WEB - панель, с помощью которой можно с легкостью решать рутинные задачи, составлять список дел абсолютно без ограничений и платных подписок. 
Вы можете составлять список дел, добавлять ярлыки любимых сайтов, следить за временем, узнавать сколько дел вы сделали в разделе статистика, заводить таймер. 
Вся информация хранится локально, в вашем браузере. 
Вы также сможете скачать с репозитория данный сервис, и разместить его у себя развернув локально на компьютере. 
Чтобы разместить локально на ПК, ничего не требуется. Просто скачайте, распакуйте, пройдите настройку и готово!
